# ProEdit

Professional video editing software for web, inspired by Premiere Pro and DaVinci Resolve workflows.

## Features

- Multi-track timeline
- Media library with drag-and-drop support
- Video/audio track management
- Preview playback panel
- Project properties and effect panels
- Express backend for uploads/export

## Getting started

### Install dependencies

```bash
npm install
```

### Start the app

```bash
npm run dev
```

### Start the backend

```bash
npm run server
```

### Run both together

```bash
npm run dev:full
```

The frontend runs on `http://localhost:5173` and the backend runs on `http://localhost:3000`.
